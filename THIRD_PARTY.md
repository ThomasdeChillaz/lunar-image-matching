# Third-party sources

## LoFTR and structural research hypotheses

LoFTR inference uses Kornia 0.7.4 (Apache-2.0), already pinned in requirements-lock.txt. The original LoFTR project is Apache-2.0: https://github.com/zju3dv/LoFTR . Outdoor weights come from the Kornia-maintained Hugging Face repository, revision `0fb3b456cf176746709c38fa9cf80695a1c82dac`, whose model card declares MIT: https://huggingface.co/kornia/loftr . Weight SHA256 and every LoFTR implementation source hash are recorded in `loftr_model_lock.json`. Weights remain outside Git. This is the MegaDepth-trained model, not JPL's lunar-trained LoFTR.

`structural_matchers.py` is original 2D experimental code inspired by local self-similarity in Heinrich et al., *MIND*, Medical Image Analysis 2012, https://doi.org/10.1016/j.media.2012.05.008 , and structural/radiometric invariance in Li et al., *RIFT*, TIP 2020, https://ljy-rs.github.io/web/Files/TIP2020.pdf . It does not copy their code or claim full method reproduction. The expanded physical subset retains the original MoonAnything CC BY 4.0 attribution and source provenance below.

## Learned model
LightGlue source is pinned to `eb42fee2d71449efb0aa5c10549752b5d75384d8` in requirements-learned.txt. Its inference code and pretrained LightGlue weights are Apache-2.0: https://github.com/cvg/LightGlue/blob/eb42fee2d71449efb0aa5c10549752b5d75384d8/LICENSE . Citation: Lindenberger, Sarlin and Pollefeys, *LightGlue: Local Feature Matching at Light Speed*, ICCV 2023, https://arxiv.org/abs/2306.13643 .

DISK features use Kornia's wrapper around the depth-supervised pretrained DISK model. Upstream code/weight source: https://github.com/cvlab-epfl/disk , revision `8dc6d4d65b47210f629e21ad1fbfb56944b11696`, Apache-2.0. Citation: Tyszkiewicz, Fua and Trulls, *DISK: Learning local features with policy gradient*, NeurIPS 2020, https://arxiv.org/abs/2006.13566 . Kornia: Apache-2.0, https://github.com/kornia/kornia .

DISK replaces the originally suggested SuperPoint extractor because the upstream LightGlue documentation flags a distinct restrictive license for SuperPoint. This project does not redistribute either model's weight files. Model URLs and SHA256 values are pinned in model_lock.json. Cached files are checked before loading; downloads are an explicit command.

## Lunar observations
CNSFM research subset: source revision and source image metadata in lunar_manifest.json; citation and use conditions in DATASET_CARD.md. The source repository supplies no dataset-specific license. Source rasters, executable and crater-detector weights are not bundled. The published paper is the source for the three site identities. We do not use its executable or crater detections to produce evaluation references.

# Research extension additions

- **MoonAnything / LunarPhoto**, Grethen et al. (2026), [Zenodo record 18415119](https://zenodo.org/records/18415119), CC BY 4.0. The experiments use the authors’ physical Hapke lighting renders, real orthorectified LRO appearance crops and original metadata. These source types remain distinct. ZIP-member CRC32, selected bytes and SHA256 are retained; the complete outer archive MD5 is not claimed. Original archives/rasters are downloaded separately and excluded from Git. Cite the authors and dataset when sharing figures or adapted results.

## Additional development matchers — 30 October 2026

- **EfficientLoFTR (CVPR 2024):** original author repository `zju3dv/EfficientLoFTR`, pinned revision and every source hash in `eloftr_model_lock.json`. The actual downloaded revision's LICENSE is Project Registration License (PRL) v1.0, 2026, allowing academic/research/education/evaluation/personal use without registration. It must not be described as Apache-2.0. Original Google Drive weight bytes and safely extracted tensor bytes are separately pinned; neither downloaded code nor weights are redistributed in this repository. The wrapper uses author full defaults and required author reparameterization, with native masking/common geometry and separately labelled resize variants.
- **MatchAnything:** official paper/project and author Hugging Face release `LittleFrog/MatchAnything`, revision and 44 source-file checksums in `matchanything_model_lock.json`. Released source LICENSE is Apache-2.0. Author weight archive, extracted ELoFTR checkpoint and safe tensor conversion are pinned and kept outside Git; weights remain subject to the authors' applicable terms. The wrapper uses the actual released architecture/defaults/configuration, strict 447-tensor loading, declared positional-encoding scale and the released MatchAnything branch's no-reparameterization behavior. It is a common-protocol integration, not a reproduction of the paper's task-specific results.
- Both wrappers keep optional additions from `requirements-eloftr.txt` in a separate dependency target. The validated core environment remains on its original pinned NumPy/PyTorch/Kornia versions. Model downloads and original weights are explicit preparation steps; there is no fallback substitution.
