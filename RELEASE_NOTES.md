# v0.1.0 - Reproducible lunar matching pilot

Full software workflow: checksummed real LROC acquisition, region-separated data manifest, masked shared-grid loading, NCC/SIFT and pretrained DISK/LightGlue matching, preprocessing ablation, exact-transform controls, frozen evaluation, machine-readable results, figures, two-page report and offline interactive viewer.

Includes a local landmark-review page and validated annotation import for replacing provisional map references with independent checkpoints. Independent checkpoint validation and associated map uncertainty remain open scientific acceptance items. This release does not certify lunar navigation accuracy.

Source images and model weights are downloaded from pinned upstream sources and are not bundled. Code and weight revisions/checksums, source image provenance, environment locks and executed source hashes are included. See README.md for reproduction and THIRD_PARTY.md for notices.
