# Same-case ARM modern matcher pilot outcome

The published protocol froze eight native 512-pixel development cases for LoMa-R, RoMa v2, the frozen compact control and SIFT. The comparison used the same reference geometry and estimated-Sun track. No calibration or final case was included. The public release archive was independently verified by size and SHA-256, and the ticket branch had one signed commit containing only the ticket.

GitHub Actions run 41926059385 reached a Linux ARM64 worker with native BF16. The original watchdog confirmed the checkout, transport and four author checkpoint downloads. It stopped after 43.96 seconds of watchdog wall time during reference-asset validation. The evaluator never started and the run produced **0 of 32 planned matcher rows**.

A separate arithmetic-only probe on Linux ARM64 with glibc 2.39 compared eight unique archived catalogues across 32 historical reference archives. All eight reproduced the exact catalogue membership, row order, coarse mask and availability. Recomputed direction values differed in 3,860 of 13,134 rows by at most `1.1102230246251565e-16`, including the four pilot reference units. The original bit-for-bit check failed for every catalogue. All eight passed an absolute `2e-15` bound, and the probe rejected controls with changed lattice membership, masks or material vector changes. This confirms the portability issue and qualifies the narrow arithmetic check. The next version still needs a signed relay and a fresh separately admitted run.
