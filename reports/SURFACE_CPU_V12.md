# Same-worker CPU validation of the surface method

The frozen28,272-parameter surface pipeline reproduces **54/72 correct raw poses**,16 strict and three wrong proposals on the supported ARM CPU worker. Every primary/strict case status agrees with the local experiment. This is a deterministic geometry correction using an image-estimated query pose and reference terrain, not a newly learned architecture.

On the existing fixed16-case bank, both surface and RoMa-v2 fast/common512 recover12/16 poses (six strict). Median full inference is **4.43s versus53.31s**, with a **12.03× median paired speedup**. The descriptive four-component resampling interval is **11.80–12.10×**. Both models were loaded and warmed in the same worker, with two configured CPU threads and alternating case order; fresh features were used for both on paired cases. Initialization, download and reference scoring are excluded. All failure cases remain in the timing/accuracy denominators. The timing sample has16 cases, not72 independent timing measurements.

The earlier complete RoMa-v2 common-profile study gives53/72 on the same content; the new RoMa repeat covers only the16 timing cases. The new surface score covers all72. Native source/input/checkpoint/model/control/metric hashes, both analytic controls, all88 saved records, exact case/timing assignment, every aggregate and paired ratio replay independently. No calibration/test pixels. Both models together peak at3.74GB process memory; that is not isolated per-method memory.

The **57/72 SIFT-first surface variant has not received this same-worker timing experiment**. The12.03× result applies only to the54/72 surface pipeline. The full72 accuracy comparison interval against RoMa includes zero, and only four previously exposed terrain components/eight geometries are represented. The timing interval is descriptive on those components, not deployment or general hardware confidence. Generic frozen large weights and lunar-trained small weights do not isolate architecture or adaptation effects. RoMa-v2 default precise800/1280 bidirectional inference and remaining native baselines are not completed. Global SOTA,1% accepted-error/nonoverlap, fresh validation and orbital accuracy remain unestablished.
