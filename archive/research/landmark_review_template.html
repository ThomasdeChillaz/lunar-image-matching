Independent lunar landmark review

Identify the same stable physical landmark in both images. Prefer a recognizable crater rim intersection or rock; avoid shadow boundaries and ambiguous crater centers. Work from the images alone. No matcher predictions or proposed coordinates are shown. Aim for 10–20 well-distributed points per pair. If too few landmarks are visible, mark the pair unscorable and explain why.

All coordinates refer to the original 512-pixel review grid regardless of zoom. Estimated picking uncertainties are per-image pixel distances, not calibrated statistical confidence intervals. Source image hashes and map bounds are bound to this packet. A second reviewer should work independently in a separate packet.


Progress stays in this browser’s local storage. Save the JSON file before clearing browser data. Empty or unfinished pairs remain unreviewed.
