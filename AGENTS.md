# Working on this repository

Read STATUS.md, AI_PLAN.md and MILESTONES.md before editing.

Maintain current interfaces in src/lunar_matching and tests. The computational
history is under archive/research; preserve its tracked bytes, manifests, models,
results and original scientific accounting. The archived AGENTS.md applies there.
The root reports directory is a public mirror of previously published evidence.
Make new research versions separately; never relabel consumed data as a fresh test.

Run the maintained tests, full archived regression, byte-preservation audit and a
fresh generated smoke after interface/matching changes. Replay saved metrics after
changes to evidence handling. A new scientific inference or training run requires
its existing compute admission; software tests and saved-output replay do not
authorize new lunar experiments. Recompute scientific results if their algorithm,
data or scorer changes. Never infer model accuracy from generated software controls.

Keep private email, drafts, credentials and execution authority out of Git. Never
send email automatically. Update current status and commit without rewriting history.
